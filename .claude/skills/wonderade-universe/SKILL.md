# Wonderade Universe

The single source of truth for making Wonderade brand content that looks like
ONE universe instead of a new hallucination per clip. It has three parts:
the asset registry (registered Higgsfield elements + model sheets), the
locked style recipe, and the enforced workflow.

## Why this exists

A 4-segment story was generated by pasting one flat PNG into each video
prompt independently. Every segment reinvented the characters and the arena —
the user called it "insanely sloppy … looks like nonsense." The fix is
mechanical, not artistic: **never describe a character from memory; always
reference a registered element by ID, and never animate a scene whose still
frame hasn't been approved.**

## The workflow, enforced: board → lock → animate

1. **BOARD** — for each distinct scene/shot setup, generate a cheap STILL
   first (`nano_banana` family, ~1.5 credits, 16:9) using the registered
   character elements via `<<<element_id>>>` placeholders. One still per
   distinct composition/location.
2. **LOCK** — show the stills to the user. Do not proceed until they approve
   the look. If a location/prop will recur, register the approved still as a
   reusable element too (environments stay consistent the same way characters
   do). Fix off-model results at this stage — a bad still costs ~1.5 credits,
   a bad video costs 90–135.
3. **ANIMATE** — only then fire video generations (`seedance_2_0`), passing
   the SAME `<<<element_id>>>` references plus the approved still as the
   frame reference where supported. One scene at a time for new territory;
   batch only once a scene family is proven.

Never skip straight to video for a new character, new location, or new
composition. Re-use of an already-locked scene family may go straight to
animate.

## Locked style recipe (video)

Full detail in [references/style.md](references/style.md). The short form —
every Wonderade animated video uses:

- 2D cel animation in the characters' exact art style, bold navy `#374191`
  outlines, flat colors.
- Hand-drawn anime cadence **on twos (~12fps)**: held key poses, smear +
  white emphasis frames — explicitly "NOT smooth AI interpolation".
- **Locked camera, hard cuts** between distinct committed compositions. No
  drifting/floating camera.
- Anime **speed-line / radial-burst rush backgrounds** for action.
- Genuinely happy/positive expressions that **shift shot to shot** — never a
  frozen smile.
- Music: uplifting **modern synthwave**. Music only — no voice, no dialogue,
  no lyrics, no on-screen text (diegetic scoreboards/numbers are the one
  allowed exception when story-critical).

## Universe rules

- Fruit world: **players/heroes are fruit WITH arms and legs**; **crowds are
  round limbless berries with simple happy cartoon faces** (described
  generically — never named after existing IP). Pip follows the limbless rule.
- Environments recur: register any approved location still as an element and
  reuse it. Details in [references/environments.md](references/environments.md).

## Higgsfield operational gotchas

- **Element syntax:** embed `<<<uuid>>>` in the prompt text; do not pass
  elements via the medias array.
- **nano banana media role** must be `image` (NOT `image_references`).
- **Content filter:** combat verbs ("punch", "power up", strike-by-strike
  wording) trigger false-positive NSFW rejections — frame all action as
  sport/training/effort. Flagged jobs don't bill.
- **Preset interception:** pass `declined_preset_id` preemptively — known
  interceptors: "IN THE DARK" `24bae836-2c4a-48e0-89b6-49fcc0b21612`,
  "KUNG FU HIT" `5bbf4a3f-e252-4c3b-84f4-29ce3fb88188`.
- **Multi-shot:** native multi_shots/multi_prompt fields are silently dropped
  by the MCP. Describe the hard-cut shot list inside a single prompt instead —
  works up to the 15s cap with continuous audio.
- **Costs (seedance_2_0):** 1080p std ≈ 90cr/10s, 135cr/15s; 720p std ≈
  45cr/10s. Always check `balance` before a multi-clip spend.
- **Sandbox network:** the remote sandbox cannot download from the Higgsfield
  CDN or upload files — import assets server-side with `media_import_url`
  (e.g. from wonderade.us); stitch scripts run on the user's machine.
- **Server name rotates** between reconnects — reload tools via ToolSearch
  and expect permission re-prompts after a reconnect.
- **Stitching >15s cuts:** copy the verified pattern in
  `scripts/stitch-princess-punch-kungfu.sh` (acrossfade audio chain +
  0.75s/side video trim; `--music` mode for a single track). The available
  static ffmpeg lacks `xfade` — don't use it.
